# Weight Tracker

A self-hostable, offline-capable React PWA for tracking daily weight. All data stays in your browser.

This project is in early development. See [docs/SPEC.md](docs/SPEC.md) for what it will do and [docs/PLAN.md](docs/PLAN.md) for the build plan.

## Development

Requires the Node version in `.nvmrc`.

```bash
npm install
npm run dev
```
